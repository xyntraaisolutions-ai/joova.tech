# Joova Brand Kit

Everything needed for Joova branding, packaging and the website. Version: Sep 27, 2026. Joova Band colors: Black, Blue, Green, Orange, Red (woven loop, silver buckle, graphite tracker).

| Folder | What's inside | Who uses it |
| --- | --- | --- |
| 01_Brand_Guidelines | Brand guidelines PDF (5 pages) and each page as PNG | Everyone |
| 02_Logo | Logo files: wordmark, symbol, horizontal lockup, app icons, favicon. SVG (vector, text outlined) and PNG | Designers, factory, website, app |
| 03_Colors | Brand colors: CSS, JSON tokens, color guide | Designers, website, printer |
| 04_Typography | Fonts (Syne, DM Sans) with licenses and type guide | Designers, website |
| 05_Packaging | Box lineup, each box (Black, Blue, Green, Orange, Red) and the back, band product images (transparent PNG), unboxing and inserts, box text EN/FR and print notes | Factory packaging team, printer |
| 06_Website | Website implementation plan (Band) and Ring add-on plan for Cursor, plus web-ready assets | Satya, website developers |
| 07_Launch_Documents | Band launch plan, brand building tips, team responsibilities (Word) | Team |

## Logo files at a glance
- `joova-wordmark-ink` / `-paper`: main logo for light / dark backgrounds.
- `joova-wordmark-on-coral` / `-on-ink`: logo with its background.
- `joova-wordmark-one-color-black` / `-white`: single-color use (engraving, one-color print).
- `joova-symbol-*`: the open-loop symbol alone (tracker pod, ring, social avatar).
- `joova-lockup-horizontal-*`: symbol + wordmark.
- `joova-app-icon-*`: app icons (rounded and square versions, 1024 px PNG).

## Before anything is printed or published [CONFIRM]
- Product features and specs on the box and website must match the factory spec sheet (wellness wording only).
- FCC ID, ISED (IC) number, importer name and address, UPC barcodes, app QR link, domain.
- Box size from the factory; printed color proof approved.
- Final factory product photos for each color (the band images here are recolored from the black sample photo).
- Lawyer: JOOVA trademark filing, design search on the loop symbol, and a check of the woven band and silver buckle design against competitor designs.
